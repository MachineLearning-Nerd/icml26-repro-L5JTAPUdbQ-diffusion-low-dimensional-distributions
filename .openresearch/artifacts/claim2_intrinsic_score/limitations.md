# Claim 2 limitations

This route independently proves the geometric cancellation that makes
low-dimensional score estimation possible and audits every displayed
dependency transition in the paper's proof. It does not independently re-prove
all concentration, tail, KDE, and mixture-weight lemmas. A faithful numerical
implementation will be run as a separate corroborating route before the final
claim verdict.

The result is conditional on exact subspace recovery. Claim 3 shows the paper's
stated assumptions do not guarantee that event for all declared subspaces;
this certificate does not conceal or repair that separate failure.
